Read `DESIGN.md`, `PRD.md`, `CURRENT_PHASE.md`, and inspect the current UI code.

Review only the UI/interaction quality that exists in the active phase.

- Visual hierarchy.
- Library/bookshelf composition.
- Book component proportions and depth cues.
- Spacing and typography.
- Motion consistency and stiffness.
- Whether the experience feels Calm — Tactile — Playful.
- Responsive behavior for resizable desktop windows.
- Accessibility concerns visible in implementation.

Return a prioritized list:

1. Critical usability issues.
2. High-impact visual improvements.
3. Motion improvements.
4. Nice-to-have polish.

Prefer small targeted changes over a redesign from scratch.
